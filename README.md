# 🌐 Dynamic Website Project

## 📌 Project Overview
This project is a **responsive dynamic website** created using **HTML, CSS, Bootstrap, and JavaScript**.  
It is designed to be visually attractive, interactive, and suitable for deployment on any **public cloud platform**.

The website displays personal information, a dynamic greeting based on time, a live clock, and a responsive image carousel.

## 🚀 Features
- 🌈 **Animated Gradient Background** for a modern look  
- 🧊 **Glassmorphism UI Card Design**  
- 📱 **Fully Responsive** (Mobile & Laptop friendly)  
- 🕒 **Dynamic Time & Greeting** (changes based on system time)  
- 🖼️ **Bootstrap Image Carousel** with 6 images  
- 🎯 **Interactive Navigation Buttons** with icons  
- ☁️ **Cloud Ready** (can be hosted on AWS, Azure, GCP, GitHub Pages)

---

## 🛠️ Technologies Used
- **HTML5** – Structure of the website  
- **CSS3** – Styling and animations  
- **Bootstrap 5** – Responsive layout and components  
- **Bootstrap Icons** – Icons for buttons  
- **JavaScript** – Dynamic time and greeting functionality  

---

## 🌍 Deployment
This website can be deployed on:
- GitHub Pages
- AWS S3
- Google Cloud Storage
- Azure Static Web Apps

Simply upload the `index.html` file to the hosting service.
